# Current Interview Trends (curated reference notes)

A short, curated snapshot used to ground the Planner Agent's strategy in how interviews are
actually run today, rather than relying purely on the LLM's own assumptions. This is a static,
human-curated reference file (not a live feed) -- see the "Grounding" section of the README for
how it's used and how to swap in live web search instead.

- **AI-assisted work is now an explicit interview topic**, not just a tool candidates use quietly.
  Interviewers increasingly ask candidates to explain, review, or debug AI-generated code rather
  than just write code from scratch -- signal has shifted toward judgment and verification skill,
  not typing speed.
- **Take-home assignments are commonly paired with a live walkthrough round**, specifically to
  verify the candidate understands and can defend what they submitted, given how easy it now is
  to generate a plausible-looking take-home solution.
- **System design questions appear earlier in loops**, even for mid-level and some senior-leaning
  intern roles -- framed as "how would you approach this at a small scale," not full
  whiteboard-scale distributed systems.
- **Behavioral rounds increasingly use structured rubrics (e.g., STAR: Situation, Task, Action,
  Result)** with active follow-up probing on vague or generic answers, rather than accepting a
  single rehearsed story at face value.
- **Collaboration and communication signal is evaluated even in technical rounds** -- interviewers
  pay attention to how a candidate talks through their reasoning out loud, not just whether they
  reach the correct answer.
- **"Day in the life" / pairing-style rounds are more common** than purely abstract algorithm
  puzzles, especially outside big tech, since they better predict on-the-job performance.
- **Take-home and coding rounds increasingly reward asking clarifying questions early** over
  diving straight into a solution -- ambiguity is often left in the prompt on purpose.
